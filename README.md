My focus is practical AI engineering — combining strong software fundamentals with modern model tooling to build systems that are useful, reliable, and easy to evolve.

- Python backends with FastAPI and distributed services

- AI-first products where models are part of the architecture, not a bolt-on feature
- Developer tooling, experimentation, and production automation
